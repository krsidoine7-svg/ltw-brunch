# 🐙 GITHUB.md — Bonnes Pratiques Git & Stratégie de Versionnement

## 🌿 1. Conventions de Branches
- `main` / `master` : Code de production stable.
- `feature/ticket-generator` : Développement du composant de billet mobile.
- `feature/poster-studio` : Studio de personnalisation des affiches.
- `docs/prompt-specifications` : Documentation et bibles fonctionnelles.

## 📝 2. Messages de Commit (Conventional Commits)
- `feat(ticket): ajout de la génération canvas format mobile 350x650px avec QR code`
- `feat(poster): intégration de l'upload photo et des badges d'invité`
- `docs(prompt): création des 12 fichiers de spécifications PRD, TDD, Design System`
- `fix(webhook): correction du format du payload JSON envoyé vers Make`
